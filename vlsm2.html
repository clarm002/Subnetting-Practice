Method — how to work VLSM
  1. Sort the host requirements from largest to smallest — biggest blocks get allocated first so everything stays aligned.
  2. For each subnet, find the host bits n where 2ⁿ − 2 ≥ hosts needed. The prefix is /(32 − n) and the block holds 2ⁿ addresses.
  3. Allocate blocks back-to-back from the base network. Each subnet's network is the previous subnet's broadcast + 1.
  4. For each block: broadcast = network + blocksize − 1; first usable = network + 1; last usable = broadcast − 1.
Work out a subnet's broadcast correctly to reveal the next subnet's start. In each separator, type 1 into the base mask to borrow host bits — borrowed bits shade purple and the readout shows the prefix and how many hosts the remaining host bits hold. Then Check my work.
