Method — how to work it out
  1. Convert the IP and subnet mask to binary using the place values 128 64 32 16 8 4 2 1.
  2. Logical AND the two rows to get the Network Address  (1&1=1, 1&0=0, 0&0=0).
  3. Copy the Network Address down and set every host bit (where the mask is 0) to 1 — that's the Broadcast Address.
  4. Convert both results back to decimal.
